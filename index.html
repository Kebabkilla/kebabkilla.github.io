Orange = root (tonic). Blue = other scale tones. Click any fret to hear it. The table below spells the scale with degrees and intervals — great for teaching.

Colours = chord roles: root, 3rd, 5th, 7th, extension. Inversions move the lowest note — the bass note a bassist plays.

An interval is the distance between two notes. On bass, a perfect 5th is 7 frets up the same string (or 2 frets across to the next string). Click any interval below to hear it from the base note.

Each chord gets one bar: bass plays root–5th–octave–5th, piano guide plays the chord tones. Loop it and practise walking over it.

The song loads into the Songsterr-style player above: tab = your walking bass line, piano = comping + melody (sampled grand piano). Slow it to 0.5×, loop one bar, and learn to play underneath a real jazz song. The chord chart highlights the current chord.

Walking bass rule: root → 3rd → 5th → approach note (a chromatic or scale step into the next chord's root). That one pattern carries almost every jazz standard.
